# Бот репутации для Telegram

## Как это работает

**Поставить репутацию:**
- Ответь на сообщение человека: `+реп помог с делом, красавчик`
  → бот покажет кнопки ⭐ 1–5, нажимаешь — готово.
- Можно сразу с оценкой, без кнопок: `+реп 5 помог с делом` — сохранится мгновенно.
- Без ответа, по нику: `+реп @username текст отзыва` (тоже можно с числом сразу).
- Самому себе поставить репутацию нельзя — бот откажет.

**Посмотреть репутацию:**
- `/rep` — своя репутация
- `/rep @username` — репутация человека по нику
- Ответ на сообщение человека командой `/rep` — тоже сработает
- Показывается звёздная шкала (⭐⭐⭐⭐☆) и последние отзывы

Бот сам считает средний балл и хранит все отзывы в базе (SQLite, файл `reputation.db` создаётся автоматически).

**Про кнопки:** пока сообщение с кнопками не обработано (перезапуск бота), выбор оценки сгорает — придётся написать `+реп ...` заново. Это ограничение хранения "в памяти", для чата это не критично.
